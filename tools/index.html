01 · Diaporama et orientation

AUTO-NEXT est un sélecteur matériel : en fonctionnement batterie, il autorise ou bloque le réveil RTC. Les horaires sont ceux du RTC, sans gestion automatique de fuseau horaire. Orientation sans effet sur les fichiers natifs EPD.

L'export EPD ne nécessite pas de cache. Mesurez la tension avec un multimètre avant de modifier le coefficient de calibrage.

          03 · INSTALLATION USB
          
Flasher le cadre en mode BOOTSEL

          
    
            
  1. Téléchargez le fichier .uf2 ci-dessus. Ne le décompressez pas et ne le copiez pas sur la carte microSD.
    2. 
            
  2. Connectez le cadre par un câble USB de données. Laissez la carte microSD en place ; son contenu sera conservé.
    3. 
            
  3. Maintenez BOOT, appuyez brièvement sur RUN, puis relâchez BOOT. Si besoin, débranchez l’USB, maintenez BOOT, rebranchez l’USB puis relâchez BOOT.
    4. 
            
  4. Ouvrez le lecteur RPI-RP2 qui apparaît sur votre ordinateur.
    5. 
            
  5. Glissez le fichier .uf2 sur RPI-RP2. Le lecteur disparaît et le RP2040 redémarre automatiquement.
    6. 
            
  6. Vérifiez le firmware. Dans Studio → Configurer le cadre → USB, connectez le port série et envoyez STATUS à 115200 bauds.
    7. 
          

          
Compatibilité : uniquement la carte Waveshare PhotoPainter RP2040 (F) 7,3 pouces, 800 × 480, 7 couleurs. Ne pas utiliser cet UF2 sur les versions RP2350 ou ESP32-S3. L'image E Ink peut rester identique après le flash : c'est normal.

        

        

          04 · EN CAS DE PROBLÈME
          
Compilation locale

          
Depuis la racine du dépôt ouvert avec PlatformIO :

          
pio run -e photopainter_rp2040

          
Le firmware est généré ici :

          
.pio/build/photopainter_rp2040/firmware.uf2

          
Sous Linux ou macOS, remplacez le chemin ci-dessous par le point de montage du lecteur RPI-RP2. Vous pouvez aussi copier le fichier avec votre gestionnaire de fichiers :

          
cp .pio/build/photopainter_rp2040/firmware.uf2 \
  "/chemin/vers/RPI-RP2/"

          
Je ne vois pas le lecteur RPI-RP2
Vérifiez le câble USB (certains ne transmettent que l'alimentation), le port et l'ordre BOOT/RUN. Fermez tout moniteur série ouvert. Vérifiez avec lsblk -f que le lecteur a été monté.

          
Upload and Monitor fonctionne mal
Si PlatformIO affiche No new RPxxxx device found yet, essayez le flash manuel UF2. Un message Verifying Flash: OK indique que l'écriture a bien été vérifiée.

          
Le site peut-il flasher directement ?
Non : le navigateur ne copie pas automatiquement le firmware sur le volume BOOTSEL. Téléchargez l'UF2, puis utilisez le gestionnaire de fichiers. Web Serial sert uniquement au diagnostic et aux commandes du firmware déjà installé.
